4. Integración Continua con GitHub Actions

Se configuró un workflow de GitHub Actions para ejecutar automáticamente las pruebas en cada push y pull request.

4.1 Workflow de pruebas

El archivo .github/workflows/tests.yml ejecuta:

  • Checkout del código
  • Configuración de Python 3.11
  • Instalación de dependencias con Poetry
  • Ejecución de pruebas con cobertura
  • Verificación de cobertura ≥ 90%
